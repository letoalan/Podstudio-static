# Module `ui-timeline-ruler`

## Rôle
dessine la règle graduée (secondes) au-dessus des lignes de la timeline.

## Dépendances
- `../core/timeline-math.js`
- `./dom.js`

## API Publique
- `renderRuler`

## Tests liés
Validation fonctionnelle et tests d’intégration.

## Exemple d'utilisation
```javascript
renderRuler(rulerEl, 90, 10); // 90 s à 10 px/s
```
