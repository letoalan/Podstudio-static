# styles/transitions.css

## Rôle
Styles pour les cartes transitions entre les blocs, la barre d'enregistrement active intégrée dans les cartes, l'inspecteur de clip de l'éditeur unifié et les boutons d'action des notifications toast.

## Sélecteurs principaux
- `.transition-card` : style visuel de la carte transition
- `.transition-rail` : pastille d'icône transition
- `.btn-rail-insert-trans` : bouton d'insertion de transition
- `.card-live-rec-panel` : barre d'enregistrement dynamique dans la carte
- `.unified-clip-inspector` : panneau inspecteur de l'éditeur unifié
- `.btn-toast-action` : bouton d'action dans le toast
