# ui/editor/clip-inspector-view.js

## Rôle
Panneau d'inspection et réglages fins du clip sélectionné dans l'éditeur unifié.

## Fonctionnalités
- Modification du nom du clip
- Curseur de volume (gain 0 % à 200 %)
- Réglages numériques en secondes : début, rognage source (offset), durée, fondu d'entrée, fondu de sortie
- Actions rapides : copier, couper, réinitialiser le rognage, supprimer

## Dépendances
- `src/ui/dom.js`
