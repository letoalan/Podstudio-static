# Module `pwa`

## Rôle
enregistre le service worker (PWA, mode hors-ligne) quand le navigateur le permet.

## Dépendances
- Aucune

## API Publique
- Module à effets de bord

## Tests liés
Validation fonctionnelle et tests d’intégration.

## Exemple d'utilisation
```javascript
await registerPwa();
```
